# 투표 앱 v1 요구사항

질문을 하나 올리면 사람들이 선택지 중 하나를 골라 투표하고, 결과를 보는 간단한 웹앱.

## 확정된 결정

| 항목 | 결정 | 비고 |
|---|---|---|
| 로그인 | 없음. 투표할 때 닉네임만 입력 | 비밀번호·회원가입 없음 |
| 중복 투표 | 막지 않음 (v1에서는 넘어감) | 같은 사람이 여러 번 투표할 수 있음 |
| 선택지 수 | 최소 2개, 최대 5개 | 빈 선택지는 허용하지 않음 |
| 결과 표시 | 표: 선택지 / 득표수 / 비율(%) / 투표자 닉네임 목록 | 그래프는 v1에서 제외 |
| 투표 개수 | 한 번에 하나만 | 새 투표를 만들면 기존 투표와 투표 기록을 덮어씀 |
| 마감 기능 | 없음 | 투표는 항상 열려 있음 |
| 기술 스택 | Python(Flask) + SQLite | 서버에 저장해서 여러 사람이 같은 결과를 봄 |

## 화면 흐름

1. **투표 만들기**: 질문과 선택지 2~5개를 입력하고 저장한다. 기존 투표가 있으면 덮어쓴다는 경고를 보여준다.
2. **투표하기**: 질문과 선택지(라디오 버튼)를 보여준다. 닉네임을 입력하고 제출한다.
3. **결과 보기**: 선택지별 득표수, 비율(%), 투표자 닉네임을 표로 보여준다. 총 투표수도 표시한다.

## 입력 검증

- 질문: 비어 있으면 안 됨
- 선택지: 공백을 제거한 뒤 비어 있지 않은 항목이 2~5개여야 함
- 닉네임: 비어 있으면 안 됨
- 선택지를 고르지 않고 제출할 수 없음
