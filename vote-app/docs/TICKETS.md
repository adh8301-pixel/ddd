# 투표 앱 v1 티켓

근거 문서: [SPEC.md](SPEC.md). 괄호 안의 "§"는 SPEC의 절 번호, "AC"는 §9 인수 조건 번호다.

순서: T1 → T2 → T3 → T4 → T5. T5는 T2 이후라면 언제든 진행할 수 있다.

```
T1 ─→ T2 ─→ T3 ─→ T4
       └──→ T5
```

---

## T1. 프로젝트 뼈대와 DB 초기화

**목표:** 빈 Flask 앱이 실행되고 DB 스키마를 만들 수 있다.

**작업**
- `requirements.txt`(flask, pytest), `app.py`, `db.py`, `schema.sql` 생성 (§3)
- `schema.sql`에 `poll`, `option`, `vote` 테이블 정의 (§4)
- `db.py`: 연결 함수(`PRAGMA foreign_keys = ON` 포함), 요청 종료 시 연결 닫기
- `flask --app app init-db` CLI 명령
- `tests/test_app.py`: 임시 DB 파일을 쓰는 pytest fixture와 test client

**완료 조건**
- [ ] `flask --app app init-db` 실행 후 `vote.db`에 테이블 3개가 생긴다
- [ ] `pytest`가 실행되고 기본 테스트 1개(앱이 뜨는지)가 통과한다

**의존:** 없음

## T2. 투표 만들기

**목표:** 질문과 선택지를 입력해 투표를 만들고, 기존 투표를 덮어쓸 수 있다.

**작업**
- `GET /`: 투표 유무에 따라 `/vote` 또는 `/create`로 리다이렉트 (§5)
- `GET /create`: 질문 입력칸 1개, 선택지 입력칸 5개(위 2개는 `required`). 기존 투표가 있으면 경고 문구 표시
- `POST /create`: 검증 (§6). 실패하면 400, 입력값 유지, 오류 메시지 표시
- 저장: 한 트랜잭션 안에서 `DELETE FROM poll` 후 poll과 option INSERT, `position`은 입력 순서
- 성공하면 `/vote`로 303 리다이렉트
- `templates/base.html`, `templates/create.html`

**완료 조건**
- [ ] AC1: 투표가 없을 때 `/`에 접속하면 `/create`로 이동
- [ ] AC3: 선택지 1개 또는 6개 이상, 빈 질문, 중복 선택지, 글자 수 초과면 400이 반환되고 DB는 변하지 않음
- [ ] AC8: 새 투표를 만들면 이전 poll, option, vote가 모두 삭제됨
- [ ] 위 항목 각각에 테스트가 있음

**의존:** T1

---

## T3. 투표하기

**목표:** 닉네임을 입력하고 선택지 하나에 투표할 수 있다.

**작업**
- `GET /vote`: 질문, 선택지 라디오 버튼(`name="option_id"`), 닉네임 입력칸, 결과 보기 링크. 투표가 없으면 `/create`로 리다이렉트
- `POST /vote`: 검증 (§6). `option_id`가 현재 투표의 선택지인지 확인
- 성공하면 vote INSERT 후 `/results`로 303 리다이렉트
- `templates/vote.html`

**완료 조건**
- [ ] AC2: 투표를 만든 뒤 `/vote`에 질문과 선택지가 보임
- [ ] AC4: 닉네임 없이 제출하면 400과 "닉네임을 입력하세요."
- [ ] AC5: 존재하지 않는 `option_id`나 선택지를 고르지 않은 요청이면 400
- [ ] AC7: 같은 닉네임으로 두 번 투표하면 vote 행이 2개 생김
- [ ] 위 항목 각각에 테스트가 있음

**의존:** T2

## T4. 결과 보기

**목표:** 선택지별 득표수, 비율, 투표자를 표로 본다.

**작업**
- `GET /results`: 투표가 없으면 `/create`로 리다이렉트
- 집계: 선택지별 득표수, 비율(소수점 첫째 자리), 투표자 닉네임을 투표한 순서대로 (§7)
- 행 순서는 `position` 순. 총 투표수가 0이면 비율 `0.0%`, 투표자 `-`
- 표 아래에 "총 N표", "투표하러 가기" 링크, "새 투표 만들기" 링크
- `templates/results.html`

**완료 조건**
- [ ] AC6: 민수→A, 지원→A, 서연→B이면 A `2 / 66.7% / 민수, 지원`, B `1 / 33.3% / 서연`, 총 3표
- [ ] AC9: 닉네임 `<script>`가 이스케이프되어 문자 그대로 표시됨
- [ ] AC10: `POST /vote` 응답이 303이고, `/results`를 다시 GET해도 표 수가 그대로임
- [ ] 투표가 0건일 때 `0.0%`와 `-`로 표시되는 테스트가 있음

**의존:** T3
